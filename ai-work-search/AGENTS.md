# Poszukiwanie bezpłatnego odpowiednika ChatGPT Work

## Cel
Znajdź **jeden faktycznie działający i zweryfikowany** produkt, który spełnia **wszystkie** poniższe warunki:
1. Legalny i dostępny w Wielkiej Brytanii.
2. Trwale bezpłatny: £0, bez karty, płatnych kont, kluczy API, próbnych kredytów oraz płatności po wykorzystaniu limitu.
3. Bez ograniczeń użycia analogicznych do limitów ChatGPT Work.
4. Pełnoprawny agent AI samodzielnie realizujący wieloetapowe zadania, w tym pracę z przeglądarką, stronami i aplikacjami (a nie tylko model czatu, MCP narzędzie lub serwer z CPU/RAM).
5. Pracuje w chmurze, bez własnego serwera, komputera czy GPU.
6. Może zostać **bezpośrednio podłączony do istniejącej rozmowy ChatGPT** i być realnie wywoływany przez tego asystenta; osobna aplikacja/web-chat nie wystarczy.
7. Nie znosi tylko pozornie limitów ChatGPT Work: ma własne bezpłatne zasoby, nie konsumuje tej samej puli Work.

## Sposób pracy
- W bieżącej sesji badawczej kontynuuj wyszukiwanie kolejnych kandydatów, gdy znaleziony nie spełnia nawet jednego warunku.
- Nie wysyłaj użytkownikowi list niepasujących aplikacji, raportów o braku sukcesu ani propozycji kompromisów, jeśli wyraźnie poprosił o wyłącznie pełny wynik.
- Wszystkie warunki sprawdzaj z oficjalnych, aktualnych źródeł: dokumentacji technicznej, cenników, regulaminów i dostępności integracji w katalogu ChatGPT.
- Nie utożsamiaj darmowego kodu na GitHubie z darmową mocą obliczeniową, a zewnętrznej wtyczki z możliwością sterowania ChatGPT.
- Nie przedstawiaj niezweryfikowanych obietnic marketingowych jako faktu.
- Unikaj ponownego proponowania rozwiązań wcześniej odrzuconych: GitHub Actions (sam sprzęt), Oracle Always Free (sam serwer), Ollama/OpenClaw uruchamiane lokalnie, AI Horde (sam model), Pollinations (limity/kredyty), Manus (limity), TinyFish (płatne kredyty), Freebuff (osobna usługa i limit), Browser Use (nie znosi limitów Work).
- Dopiero gdy wszystkie warunki będą potwierdzone, przekaż użytkownikowi nazwę, link, dowody spełnienia warunków i dokładny, możliwy do wykonania sposób podłączenia.

## Uczciwe granice
Ten dokument jest zbiorem preferencji i instrukcji do użycia **po jego odczytaniu**; **nie** steruje uruchamianiem ChatGPT, nie wydłuża pojedynczej sesji, nie obchodzi limitów usługi i nie uruchamia sam wyszukiwania. Nie wolno twierdzić, że wyszukiwanie działa stale, jeżeli nie uruchomiono odrębnej automatyzacji. Gdy system kończy sesję, nie twórz fałszywych deklaracji o dalszym działaniu.
